# Medichat-AI
Rag,llm,Document Chunking Strategies,Fallback Architecture:
* MediChat Pro is an intelligent document assistant that extracts and analyzes text from uploaded medical PDF reports.
* It utilizes RAG and FAISS vector search to retrieve precise context and answer specific questions based on your files.
* It includes a smart fallback mechanism to provide general medical advice and medicine recommendations even without an uploaded PDF.
* Built using Streamlit, LangChain, and Euri AI, it offers a user-friendly chat interface for instant health insights.
